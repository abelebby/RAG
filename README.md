 a RAG application that enables natural language question answering over legal documents. This particular application focuses on the labor laws of UAE (ie; The Federal Decree by Law No. (33) of 2021
Regulating Labor Relations. Used OpenAI 4.1-mini LLM, Microsofts MiniLM-L6-v2 embedding model and ChromaDB vector database.
